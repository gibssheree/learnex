## How to use this vault section
Each note follows the same shape, so you can compare languages fast:
- **Definition** — what it is in one or two sentences
- **Pros / Cons** — the real tradeoffs, not marketing
- **Best For** — the problems it actually fits
- **Real Examples** — software built with it, so you know it's not theoretical
- **Use Cases** — concrete scenarios to practice on

## Suggested learning order (given you already know Python, JS, TS)
1. **Go or Rust** — closest next step for backend/systems work, huge job demand
2. **SQL** — not optional, every real project needs it
3. **Bash or PowerShell** — automate your own dev workflow
4. **Kotlin or Swift** — if mobile interests you
5. **Haskell or Elixir** — to stretch how you think about problems (functional paradigm)
6. Pick one **niche** language (Solidity, Verilog, COBOL) based on what domain problem you want to explore
