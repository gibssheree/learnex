# Logic Gates

**Definition:** Logic gates are basic digital circuits that perform Boolean operations, like AND, OR, and NOT, on one or more binary inputs to produce a single output.

## How It Works
- Each gate follows a fixed truth table mapping input combinations (0s and 1s) to an output, implemented internally with transistors
- Complex gates like NAND and NOR are functionally complete, meaning any digital logic can be built from them alone

## Why It Matters
- Logic gates are the fundamental building blocks of all digital electronics, from simple counters to entire processors

## Example
An AND gate in a car's ignition circuit only allows the starter motor to engage when both the key is turned and the brake is pressed.
