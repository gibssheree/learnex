# OKRs (Objectives and Key Results)

**Definition:** A goal-setting framework that pairs a qualitative Objective with a small set of measurable Key Results used to track progress toward it.

## How It Works
- The Objective states an ambitious, memorable goal; each Key Result is a specific, numeric target that shows whether the objective was achieved
- Teams typically set OKRs quarterly and score them at 0.6-0.7 completion as a healthy target, treating consistent 1.0 scores as a sign goals were set too easily

## Why It Matters
- Aligns every team around a shared set of priorities and makes progress visible, which is critical once a startup grows beyond a size where everyone can coordinate informally
