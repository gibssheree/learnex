## How to use this
Core Concepts apply no matter which engine you pick — read those first, then let [[Unity vs Unreal vs Godot]] decide the rest of your tooling.

## Suggested order if starting from zero
1. **Game Loop → Frame Rate and Delta Time** — the two ideas everything else in game dev builds on
2. **Game State Management** — how a real game (not just a demo loop) is actually organized
3. **Entity Component System (ECS)** — how larger games structure hundreds of different object types cleanly
4. **Physics Engine and Collision Detection → Procedural Generation** — the two most common reasons to reach for a full engine instead of building from scratch
5. **Unity vs Unreal vs Godot** — once the concepts click, pick a tool and actually build something
