# Set Theory

**Definition:** The branch of mathematical logic that studies collections of distinct objects (elements).

## How It Works
- Operations: Union (A ∪ B), Intersection (A ∩ B), Difference (A \ B), Complement (A')
- Power Set P(A): set of all subsets of A (contains 2^n elements for set of size n)
- Cartesian Product (A × B): set of all ordered pairs (a, b)

## Why It Matters
- Underpins relational database theory (SQL JOINs are set operations) and programming data structures (Sets, Maps)

## Common Pitfalls
- Confusing element membership (`x ∈ A`) with subset inclusion (`{x} ⊆ A`)
