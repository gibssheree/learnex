# Relations and Functions

**Definition:** A relation defines associations between elements of sets; a function is a special relation assigning exactly one output to each input element.

## How It Works
- Equivalence Relation: Reflexive, Symmetric, Transitive (partitions set into equivalence classes)
- Partial Order: Reflexive, Antisymmetric, Transitive
- Function Types: Injective (one-to-one), Surjective (onto), Bijective (one-to-one and onto, invertible)

## Why It Matters
- Provides formal mathematical definitions for database foreign keys, type systems, and functional programming

## Common Pitfalls
- Assuming a function is invertible without first proving it is Bijective
