# Fastly

**Definition:** A CDN and edge computing company known for real-time configuration changes and developer-focused tooling.

## Core Services & Concepts
- **CDN** — [[Content Delivery Network (CDN) and Edge Computing]], known for near-instant cache purges compared to competitors
- **Compute@Edge** — [[Serverless Computing and Cold Starts]], WebAssembly-based edge compute
- **Real-time log streaming** — [[Observability and Monitoring]]

## Pros
- Fastest cache invalidation in the industry, seconds instead of minutes
- Developer-friendly VCL configuration language
- Strong real-time analytics

## Cons
- Smaller free tier than Cloudflare
- Smaller network footprint than Akamai or Cloudflare
- More expensive at small scale

## Best For
- News and media sites needing instant cache purges
- API acceleration

## Real Examples
- Used by The New York Times, GitHub, and Reddit for content delivery

## Use Cases
- News publishing platforms
- API gateways needing edge caching
- Real-time content delivery
