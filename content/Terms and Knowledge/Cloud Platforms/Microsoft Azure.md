# Microsoft Azure

**Definition:** Microsoft's cloud platform, deeply integrated with Windows Server, Active Directory, and the broader Microsoft enterprise ecosystem.

## Core Services & Concepts
- **Virtual Machines** — [[Virtual Machines (VMs)]]
- **AKS** — [[Kubernetes (K8s)]], managed Kubernetes
- **Azure Functions** — [[Serverless Computing and Cold Starts]]
- **Blob Storage** — [[Cloud Storage Systems]]
- **Entra ID (formerly Azure AD)** — [[Identity and Access Management (IAM)]], the identity backbone most enterprises already use for Windows logins
- **Cosmos DB** — [[CAP Theorem]], globally distributed multi-model database with tunable consistency levels

## Pros
- Deepest integration with existing Microsoft/Windows enterprise environments
- Strong hybrid-cloud tooling via Azure Arc
- Generous enterprise licensing deals bundled with Microsoft 365

## Cons
- Console and tooling have historically been less polished than AWS's
- Documentation quality is inconsistent across services

## Best For
- Enterprises already running on Windows Server, Active Directory, or Microsoft 365

## Real Examples
- Most large traditional enterprises, banks, insurance, government, run significant workloads on Azure

## Use Cases
- Enterprise IT modernization
- Hybrid on-prem/cloud deployments
- .NET application hosting
