## How to use this
Research & Structure happens before a single pixel is designed. Design Fundamentals is where structure becomes an actual interface. Implementation is where that interface becomes real, responsive, accessible code.

## Suggested order if starting from zero
1. **User Research and Personas → Information Architecture** — understand who you're designing for and how content should be organized
2. **Wireframing and Prototyping → Usability Heuristics** — get the layout and flow right before it looks finished
3. **Figma → Design System → Design Tokens** — how it actually gets built and kept consistent
4. **Responsive Design → Web Accessibility (a11y)** — the two things that make a design actually work for everyone, not just the tested screen size
