## How to use this
Read Core Concepts first, they're prerequisites for everything else. [[Proof of Work vs Proof of Stake]] connects directly to [[Distributed Consensus]] in [[System Design and Distributed Systems Terms MOC|System Design]] — the same underlying problem, applied to a trustless, permissionless network instead of a company's own servers.

## Suggested order if starting from zero
1. **Blockchain → Wallet → Gas Fees** — how the base layer works and what it costs to use
2. **Proof of Work vs Proof of Stake** — how the network agrees on truth without a central authority
3. **Smart Contract** — the building block everything else is made of
4. **NFT, DeFi, DAO** — the three major application categories built on smart contracts
5. **Layer 2 Scaling** — the practical fix for gas fees and throughput, once the fundamentals click
